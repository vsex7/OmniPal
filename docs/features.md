# OmniPal 功能清单

**文档版本**：v1.2.0  
**最后更新**：2026-09-15  
**对应开发文档**：OmniPal 完整开发文档

本文档列出 OmniPal 的全部规划功能，按优先级与实现阶段划分，便于开发排期与用户了解范围。

---

## 1. 核心功能（Phase 0–1，必须交付）

这些功能构成 OmniPal 的最小可用版本，必须稳定、干净、可回退。

| 功能 | 说明 | 优先级 | 阶段 |
|------|------|--------|------|
| 三模式热切换 | 支持 `windows` / `mac` / `omarchy` 三种模式瞬间切换 | P0 | Phase 0 |
| 纯内存绑定覆盖 | 通过 Hyprland Socket 直接注入/撤销快捷键，不写配置文件 | P0 | Phase 0 |
| 自动恢复（Restore） | 退出、崩溃、SIGTERM 或手动执行时恢复原始绑定 | P0 | Phase 0 |
| 基础 CLI | `switch` / `cycle` / `restore` / `status` 命令 | P0 | Phase 0 |
| 状态广播 | 向插件实时广播当前模式状态 | P0 | Phase 0 |
| 模式指示器 | 状态栏显示当前模式，左键循环切换，右键打开设置 | P0 | Phase 1 |
| 快捷键 HUD | 弹出当前模式的完整快捷键列表（Cheat Sheet） | P0 | Phase 1 |
| 简单设置面板 | 可视化切换模式、预览当前绑定 | P1 | Phase 1 |
| 优雅降级 | Engine 未运行时，插件显示禁用状态并给出提示，不崩溃 | P0 | Phase 1 |
| 干净卸载 | 一键恢复系统并清理自身文件，无残留 | P0 | Phase 0 |

---

## 2. 增强功能（Phase 2，已交付）

在核心功能稳定后实现，用于提升完整桌面体验。

| 功能 | 说明 | 优先级 | 状态 |
|------|------|--------|------|
| 基础窗口吸附 | 支持左右半屏、最大化、居中等常用布局 | P1 | 已交付 |
| 吸附视觉反馈 | 吸附操作时显示半透明几何预览（snap-feedback） | P1 | 已交付 |
| mac-dock | 屏幕底部应用 Dock，显示运行状态与快速切换 | P2 | 已交付 |
| 任务视图 | 类似 Windows 任务视图 / macOS Mission Control 的概览界面 | P2 | 已交付 |
| 多显示器支持 | 吸附与任务视图正确识别当前活动显示器 | P1 | 已交付 |

## 4. 明确不在范围内的功能

为保持架构干净并避免重蹈 Omapala 覆辙，以下功能明确排除：

- 默认写入或修改用户 Hyprland 配置文件
- 应用内快捷键拦截或重映射（如 Cmd+C / Cmd+V）
- 全局输入设备级重映射（keyd、kanata 等作为默认依赖）
- 实时鼠标拖拽吸附
- 窗口像素级缩略图抓取
- 重型使用习惯追踪与云端分析
- 自动修改 Omarchy 的 `shell.json` 布局

## 5. 功能实现优先级总结

**P0（必须，阻塞发布）**
- 三模式热切换
- 自动恢复
- 基础 CLI
- 模式指示器
- 快捷键 HUD
- 优雅降级
- 干净卸载

**P1（重要，提升完整度）**
- 简单设置面板
- 基础窗口吸附
- 吸附视觉反馈
- 多显示器基础支持

**P2（增强体验）**
- mac-dock
- 任务视图

**已交付核心与扩展（v1.0 ~ v1.1）**
- 三模式热切换与原子恢复
- 基础 CLI 与 doctor 诊断
- 模式指示器、快捷键 HUD、设置面板
- 窗口吸附与 HUD 视觉反馈
- Mac-Dock 与 Overview 任务视图
- 用户自定义 Profile 扩展与丰富吸附布局

---

## 6. 验收相关说明

所有功能在合并前需满足：
- 不破坏零配置污染原则（除非用户明确开启持久化）
- 数据来自单一事实源，无硬编码键位
- 插件在无 Engine 时可优雅降级
- 相关测试通过（单元、一致性、真机切换延迟）
