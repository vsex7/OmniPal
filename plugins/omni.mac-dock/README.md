# omni.mac-dock

OmniPal macOS 风格底部 Dock 栏（Quickshell 插件）。

## 特性

- **现代悬浮胶囊**：底部居中半透明毛玻璃 Dock 栏，符合现代 macOS 美学（纯元数据渲染，零窗口像素抓取，符合 H-5）。
- **智能运行态跟踪**：自动检测终端、浏览器、文件管理器、VS Code 等运行状态，动态显示 macOS 标志性的运行指示圆点。
- **物理鱼眼波浪放大**：鼠标位置驱动高斯衰减的连续放大波——中心图标最高 1.35x，相邻图标按距离平滑递减；离开 Dock 时弹簧衰减回落基线。
- **多窗口实例角标**：同一应用 class 聚合计数，右上角胶囊角标显示实例数；左键点击按顺序轮转聚焦下一个窗口。
- **点击弹跳反馈**：激活 / 启动应用时图标纵向弹性起跳（-13px 起跳 + OutElastic 阻尼回落）。
- **右键上下文卡片**：图标正上方弹出动作气泡——聚焦前台窗口、轮转下一窗口、新开实例、关闭该应用（`hyprctl dispatch closewindow`）；点击外部或 `Esc` 自动关闭。
- **单键唤醒/收起**：通过快捷键或 shell toggle 随时呼出与隐藏。

## 呼出方式

```bash
omarchy-shell shell toggle omni.mac-dock
```
